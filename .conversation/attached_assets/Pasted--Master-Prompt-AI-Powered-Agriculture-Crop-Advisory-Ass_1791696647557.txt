# Master Prompt: AI-Powered Agriculture Crop Advisory Assistant

## 1. Header & System Persona Role
You are an expert AI Systems Architect, Full-Stack Principal Engineer, and Agricultural Tech Lead. Your mission is to architect, build, test, and deliver a production-ready, highly robust, responsive, and secure full-stack web application named the **AI-Powered Agriculture Crop Advisory Assistant**. This platform provides farmers, agronomists, and agricultural extension workers with real-time, data-driven crop health diagnoses, soil fertility recommendations, pest and disease mitigation strategies, and localized yield optimization insights powered by Google Gemini generative AI.

## 2. Core Mission Directive
Build a complete, end-to-end web application from scratch. Every file, database migration, backend route, frontend component, Zod validation schema, and Gemini SDK integration must be fully written out with zero placeholders, `// TODO` comments, or skipped logic. The application must feature robust error handling, loading states, optimistic UI updates, strict input validation, and enterprise-grade security.

## 3. Product Goal
To bridge the gap between advanced agricultural science and everyday farming operations by delivering instant, multimodal, expert-level crop consultations. Farmers can input soil data, weather metrics, crop types, and visual symptom images to receive structured, actionable, and scientifically sound advisory reports stored securely in a PostgreSQL database for historical tracking.

## 4. Mandatory Features
*   **Multimodal Advisory Generation:** Upload crop or leaf photos alongside structured text inputs (soil pH, NPK levels, temperature, humidity, rainfall) for AI diagnosis.
*   **Interactive Advisory Dashboard:** View past reports, filter by crop type or health status, and track historical farm interventions.
*   **Structured AI Diagnostics:** Receive JSON-formatted outputs containing disease identification, confidence scores, organic vs. chemical treatments, preventive measures, and expected yield impact.
*   **Export & Share:** Export advisory reports as formatted PDF summaries or shareable links.
*   **Weather & Soil Mapping Simulation:** Input geolocation coordinates or select regions to auto-populate regional climate baseline data.
*   **Multi-Role User Profiles:** Support for Farmers, Agronomists, and Administrators with role-specific views and analytics.

## 5. Technology Requirements
*   **Frontend:** React.js (Vite), Tailwind CSS, Lucide React (icons), React Router, Shadcn/UI pattern components.
*   **Backend:** Node.js, Express.js, TypeScript/ES Modules.
*   **Database & ORM:** PostgreSQL (via `pg` pool or Prisma/Drizzle), supporting JSONB columns for flexible AI payload storage.
*   **AI Integration:** `@google/genai` SDK using `gemini-2.5-flash` for rapid multimodal reasoning and structured JSON outputs via `responseSchema`.
*   **Validation:** Zod for both client-side form validation and server-side request payload verification.

## 6. Application Pages (Routes)
*   `GET /` — Landing page with value proposition, sample advisory showcases, and quick entry.
*   `GET /dashboard` — Main user dashboard listing recent advisories, quick actions, and health statistics.
*   `GET /advisory/new` — Interactive multi-step form to input farm parameters and upload crop photos for a new AI assessment.
*   `GET /advisory/:id` — Detailed view of a specific advisory report with diagnosis cards, treatment plans, and export tools.
*   `GET /history` — Filterable, searchable archive of all past crop consultations.
*   `GET /profile` — User profile settings, farm location configurations, and role management.

## 7. User Flow
1.  **Onboarding / Entry:** User arrives at the landing page and logs in or creates a profile specifying their primary region and crops.
2.  **Initiating Consultation:** User navigates to `/advisory/new`, enters soil parameters (pH, nitrogen, phosphorus, potassium), selects the crop type and growth stage, and optionally uploads an image of affected leaves or soil.
3.  **AI Processing:** The backend receives the payload, constructs a multimodal prompt, queries `@google/genai` with structured JSON schema enforcement, and validates the response.
4.  **Reviewing Advisory:** The user is redirected to `/advisory/:id` where the structured diagnosis, treatment schedule, and preventive actions are displayed cleanly with visual severity indicators.
5.  **Tracking & History:** The report is saved to PostgreSQL, instantly reflecting in the user's dashboard and history log for longitudinal tracking.

## 8. Target Domains & Categorization
*   **Crop Categories:** Cereal Grains (Wheat, Rice, Maize), Legumes (Soybean, Lentils, Chickpeas), Horticulture (Tomato, Potato, Citrus, Apples), Cash Crops (Cotton, Sugarcane, Coffee).
*   **Issue Classifications:** Fungal Infections, Bacterial Blights, Nutrient Deficiencies (Nitrogen, Phosphorus, Potassium, Iron), Pest Infestations (Aphids, Borers, Beetles), Environmental Stress (Drought, Waterlogging, Heat Shock).

## 9. Form & Advisory Configuration
*   **Inputs Required:**
    *   `cropName`: string (e.g., "Tomato", "Wheat")
    *   `growthStage`: enum (`Germination`, `Vegetative`, `Flowering`, `Fruiting`, `Maturation`)
    *   `soilPh`: number (range 3.0 to 10.0)
    *   `npkLevels`: object (`nitrogen`: ppm, `phosphorus`: ppm, `potassium`: ppm)
    *   `temperatureC`: number
    *   `humidityPercent`: number
    *   `symptomDescription`: string
    *   `imageFile`: optional base64 image or multipart upload
*   **Advisory Output Structure:**
    *   `diagnosisSummary`: string
    *   `identifiedIssue`: string
    *   `confidenceScore`: number (0-100)
    *   `severityLevel`: enum (`Low`, `Moderate`, `High`, `Critical`)
    *   `organicTreatments`: array of strings
    *   `chemicalTreatments`: array of strings
    *   `preventiveMeasures`: array of strings
    *   `estimatedYieldImpact`: string

## 10. Database Schema (Production SQL for PostgreSQL)
```sql
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

CREATE TYPE user_role AS ENUM ('farmer', 'agronomist', 'admin');
CREATE TYPE severity_level AS ENUM ('Low', 'Moderate', 'High', 'Critical');

CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    email VARCHAR(255) UNIQUE NOT NULL,
    full_name VARCHAR(255) NOT NULL,
    role user_role DEFAULT 'farmer',
    region VARCHAR(100),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE advisories (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    crop_name VARCHAR(100) NOT NULL,
    growth_stage VARCHAR(50) NOT NULL,
    soil_ph NUMERIC(4, 2) NOT NULL,
    npk_nitrogen INTEGER NOT NULL,
    npk_phosphorus INTEGER NOT NULL,
    npk_potassium INTEGER NOT NULL,
    temperature_c NUMERIC(5, 2),
    humidity_percent NUMERIC(5, 2),
    symptom_description TEXT,
    image_url TEXT,
    ai_diagnosis_json JSONB NOT NULL,
    severity severity_level DEFAULT 'Moderate',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_advisories_user_id ON advisories(user_id);
CREATE INDEX idx_advisories_crop_name ON advisories(crop_name);
CREATE INDEX idx_advisories_created_at ON advisories(created_at DESC);
